DeepSeek-OCR is positioned as a proof-of-concept for what the authors call "contexts optical compression": instead of storing long text contexts directly as tokens, the system renders them as images and then compresses those images into a small number of vision tokens, effectively letting the model "read" far more text than its token budget would normally allow. The architecture pairs a DeepEncoder with a DeepSeek-3B-MoE decoder. The encoder, around 380M parameters, serially connects SAM-base and CLIP-large through a 16× convolutional compressor, which lets it process high-resolution inputs with low activation memory while emitting very few vision tokens. The decoder activates roughly 570M parameters from the MoE model and reconstructs the underlying text from those compressed latent tokens. The result is near-lossless OCR at compression ratios below 10×, with decoding precision around 97%, and it still retains about 60% accuracy even at 20× compression. On OmniDocBench, DeepSeek-OCR outperforms GOT-OCR2.0 using only 100 vision tokens per page and beats MinerU2.0 with fewer than 800 vision tokens, showing that a handful of visual tokens can decode text quantities far exceeding the token count itself.

The system supports a range of dynamic resolution modes, from 64 up to 400+ vision tokens, which lets the model trade compression ratio against accuracy depending on the task. These modes include tile-based configurations like Gundam, which combines local 640×640 tiles with a global view, and Gundam-master, which upsizes both local and global views for very text-dense documents like newspapers. Training is deliberately staged: the DeepEncoder is first trained independently with next-token prediction on OCR data plus 100M LAION samples, and then the full DeepSeek-OCR model is trained with pipeline parallelism on a mix of document and scene OCR, chart and formula parsing, general vision data, and text-only data. This mixture preserves general vision abilities such as image description, object detection, and grounding, so the model is not just an OCR engine but a compressed-context reader that still understands images broadly.

The broader claim is that this optical compression approach validates a new way to handle ultra-long contexts. By simulating human memory decay, historical text can be rendered as images and progressively downsized as it ages, so older parts of a conversation or document consume fewer tokens while newer parts retain higher fidelity. DeepSeek-OCR handles nearly 100 languages in PDFs and can decode more than ten times as many text tokens as the number of vision tokens it receives, which the authors argue makes it a practical and scalable alternative to purely textual long-context mechanisms. The paper is framed as a demonstration that the bottleneck for long-context understanding can be shifted from text token count to visual compression, with promising accuracy even at aggressive compression ratios.
